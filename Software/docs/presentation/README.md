coordinates, helpers in `dio.py`). Change the script, run it, then export: `bash diagrams/src/export.sh [name …]`

When several arrows mean the same thing, give the diagram a legend (`Diagram.legend`) instead of labelling one
of them.

Example numbers in the animations (ADC codes, levels, curve shapes) are illustrative, not measurements.

Render (from `animations/`, Python 3.12 venv with `manim==0.19.0`, no LaTeX needed):

```sh
uv venv --python 3.12 .venv && uv pip install --python .venv/Scripts/python.exe manim==0.19.0
bash render.sh                 # all scenes → videos/
bash render.sh PllSynthesis    # one scene
```

## German version

Same diagrams and videos with German labels, for the German slides. Exported only: the repo documentation links the
English files. Output: `de/diagrams/*.png|svg` and `de/videos/*.mp4`.

All labels go through `i18n.py`: `SNA_LANG=de` looks each English string up in `i18n_de.py` (whole label first,
then line by line) and switches decimal points to commas; commands, JSON, part numbers and signal names stay as they
are. A new or changed English label needs its German entry; strings without one stay English and are listed with
`SNA_I18N_REPORT=<file>`.

```sh
cd diagrams/src
for b in build_hw.py build_rf.py build_fw.py; do SNA_LANG=de python $b; done   # → de/drawio/ (not committed)
SNA_LANG=de bash export.sh                                                    # → de/diagrams/
cd ../../animations && SNA_LANG=de bash render.sh                             # → de/videos/
```
